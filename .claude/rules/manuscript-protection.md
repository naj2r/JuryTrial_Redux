# Manuscript Protection Rule

**The user writes the paper. Claude does not write prose in the paper without explicit instruction.**

## Scope: What's Protected vs. What's Autonomous

| Layer | Files | Claude Autonomy |
|-------|-------|-----------------|
| **Manuscript (protected)** | `Paper/sections/*.tex`, `Paper/main.tex` | Mechanical fixes only — no substantive writing without explicit instruction |
| **Manuscript (unprotected)** | `Bibliography_base.bib`, `Tables/*.tex`, `Preambles/*.tex` | Full autonomy — these are infrastructure |
| **Project Book** | `ProjectBook/*.qmd` | **Full autonomy** — Claude writes, expands, and edits freely |
| **R scripts** | `scripts/R/*.R` | **Full autonomy** — Claude writes and modifies code |
| **Session logs & notes** | `quality_reports/**`, `explorations/**` | **Full autonomy** — internal working documents |

**The Project Book is Claude's workspace.** Write detailed notes, draft prose, expand chapters — all fine. The user draws from these when writing the paper themselves.

## Protected Files

The **prose sections** of the paper are manuscript-protected:
- `Paper/main.tex` (body text)
- `Paper/sections/*.tex` (if section files exist)

**NOT protected** (infrastructure — Claude has full autonomy):
- Tables in `Tables/*.tex` — generated by R scripts
- Figures in `Figures/` — generated by R scripts
- Bibliography `Bibliography_base.bib` — reference management
- Preambles `Preambles/*.tex` — LaTeX configuration

## What Claude MAY Do to Protected Files (Without Asking)

| Action | Example | Why OK |
|--------|---------|--------|
| Fix broken BibTeX keys | `oldkey2009wrong` → `author2009right` | Mechanical — no prose changed |
| Fix LaTeX compilation errors | Missing `}`, undefined `\ref` targets | Mechanical — preserves user's text |
| Add `\input{}` for new tables/figures | Wiring a new table into the paper | Infrastructure — no prose changed |
| Update numbers to match R output | Coefficient from 0.45 to 0.42 after re-run | Data-driven — keeping paper accurate |

## What Claude MUST NOT Do (Without Explicit User Instruction)

| Action | What Should Happen Instead |
|--------|---------------------------|
| Write or rewrite prose paragraphs | Put draft in ProjectBook QMD, user moves it |
| Change the narrative or framing | Suggest in session log or chat |
| Delete user content | Comment it out at most, or ask first |
| Add TODO comments into .tex | Put suggestions in session log instead |
| Draft paragraphs into .tex | Put draft in `quality_reports/drafts/` or QMD |

## The Test

Before editing any protected file, ask:

> **Did the user explicitly request this specific change in this conversation?**

- If YES → proceed.
- If NO but it's a mechanical fix (broken key, compilation error, number update) → proceed.
- If NO and it involves prose, structure, or content → **STOP. Do not edit.**

Put the suggestion in a session log, quality report, or ProjectBook QMD chapter instead.
