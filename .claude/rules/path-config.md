**When asked to read, edit, or create any file, use the routing rules below.**

## File Routing Rules

### Code Files (.do, .R)
- **Read/Edit:** Look in repo `scripts/stata/michigan/` first, then `$RB/code/michigan/`
- **Create:** Always create in repo `scripts/stata/michigan/`
- **Execute:** Run from `$RB` (Stata needs data access)

### Data Files (.dta, .csv raw data)
- **Read:** `$RB/data_raw/michigan/`, `$RB/data_intermediate/michigan/`, `$RB/data_final/`
- **NEVER** copy data files into the repo

### Result CSVs
- **Read:** `$RB/output/results/mi_*.csv`
- **NEVER** copy result CSVs into the repo

### Paper (.tex)
- **Read/Edit:** `$OL/Sections/*.tex` (Overleaf is authoritative)
- **Manuscript protection rules apply** — see `manuscript-protection.md`

### Generated Tables (.tex)
- **Read:** `$OL/files/tab/mi_conference/*.tex`
- These are generated by `08_conference_tables.do` — never edit manually

### Quarto Book (.qmd)
- **Read:** `$RB/replication_book/*.qmd`
- QMD files stay in Dropbox

### Quality Reports / Plans / Session Logs
- **Read/Write:** Repo `quality_reports/`

### Stata Logs
- **Read:** `$RB/*.log` (never in repo)

## Stata Execution Rule

ALWAYS use PowerShell batch mode:
```powershell
& "C:\Program Files\StataNow19\StataMP-64.exe" /e do "C:\path\to\file.do"
```
Never run Stata from bash. Never use `stata -b`. The `/e` flag runs in batch mode and exits.
